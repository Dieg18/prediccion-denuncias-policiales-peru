# Predicción de denuncias policiales por distrito en el Perú

Proyecto del curso de Inteligencia Artificial.

## Objetivo
Predecir la tasa mensual de denuncias policiales por distrito en el Perú mediante aprendizaje automático y variables sociodemográficas.

## Datos utilizados
- Denuncias policiales por distrito y mes.
- Población proyectada por distrito.
- Índice de pobreza distrital.

## Modelos propuestos
- Random Forest
- Gradient Boosting
- K-Nearest Neighbors (KNN)
